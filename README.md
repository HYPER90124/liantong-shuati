# 联通备考 · 刷题与资料

2027 中国联通笔试备考的移动端应用。把原课程的题库和 PDF 资料整理成了适合手机使用的 PWA：

- **刷题**：29 套试卷、4054 道题（历年真题 / 模拟卷 / 专项练习）
- **资料库**：49 份课程 PDF（讲义、真题、专业知识）

## 在线使用

- **地址**：https://hyper90124.github.io/liantong-shuati/
- 手机浏览器打开后，建议「添加到主屏幕」，即可像 App 一样全屏使用并离线刷题。

| iPhone / iPad (Safari) | Android (Chrome) |
| --- | --- |
| 分享按钮 → 添加到主屏幕 | 右上角菜单 → 安装应用 / 添加到主屏幕 |

## 功能

- 首页两个入口：刷题练习、PDF 资料库
- 试卷列表：按「历年真题 / 模拟卷 / 专项练习」分类，支持搜索
- 题型支持：单选、多选、材料题、完形填空（一篇材料 + 10 个空）
- 顺序 / 随机 / 错题 / 收藏 四种练习模式
- 背题模式：一键显示答案与解析
- 答题即时判对错，自动展开解析，可单题「重做」
- 答题卡总览，点击题号跳转，可一键跳到下一道错题
- 每套试卷独立记录进度，自动保存在本机
- 深色模式、左右滑动切题、键盘方向键切题
- PWA：可安装到桌面，已看过的题库和图片离线可用
- PDF 资料按课程分类展示，显示文件大小，点击用原站打开 / 下载

## 本地运行

纯静态站点，无需构建：

```bash
npx serve .
# 或
python -m http.server 4173
```

访问 `http://localhost:4173/`。

## 目录结构

```
index.html              页面骨架
styles.css              样式（移动端优先 + 深色模式）
app.js                  路由与交互逻辑
data/index.js           课程信息、试卷目录、PDF 目录
data/papers/<id>.js     每套试卷的题目数据（按需加载）
assets/img/             题目图片（本地化，1532 张）
manifest.webmanifest    PWA 配置
sw.js                   Service Worker（离线缓存）
```
